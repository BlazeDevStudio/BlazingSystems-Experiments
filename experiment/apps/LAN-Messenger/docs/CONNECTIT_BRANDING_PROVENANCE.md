# ConnectIT logo provenance — LAN Messenger visual integration

The owner-provided ConnectIT branding is preserved byte-for-byte, including
master and variant SVGs, pixel-size PNGs, Windows ICO, and Android adaptive
foreground/background icons (18 files), in `assets/branding/connectit/`.

Source archive: `ConnectIT-LAN-Messenger-Draft-v0.1.4-Node-Revocation-Renewal.zip`
in the private ConnectIT Development Google Drive folder (file ID
`17_O8TXNQ3ZgSAoRfFmqPjqOQclIISCir`). The source is original artwork,
not a redrawn approximation. Original file fingerprints are covered by tests.

The Flutter app bar, Windows tray, executable icon and Android launcher
icons use the supplied artwork. The old CI-generated Windows pixel bubble
has been retired from the generator.

This is a logo-only integration. LAN Messenger retains its local identity,
package name, offline LAN communication, and existing call/file architecture.
ConnectIT Master/Seed federation, account authentication, SecureBind and WAN
routing remain separate experiments; the branding change does not enable them.

This draft is not released until exact-source Windows/Android CI and emulator
tests pass. Physical Windows video crash regression and Android upgrade
signing continuity remain unresolved release-readiness gates.
