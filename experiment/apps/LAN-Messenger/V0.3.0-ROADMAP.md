# LAN Messenger v0.3.0 — Regression Repair and Group Hardening

Base: published v0.2.10 preview source (5425003535ec36ac70ade4ff15347ad1e6f34075).

## Repair work

- Native Answer/Decline presentation is background-only on Windows and Android.
- Windows Win32 popup reconciles when minimizing, restoring, focusing or hiding to tray, refuses a late foreground popup and targets the monitor hosting Messenger.
- Android CallStyle notification Answer uses an explicit user-initiated Activity PendingIntent instead of broadcast-to-activity background launch; stale Answer actions are ignored.
- Blocked Android background activity launches no longer crash through the native handler.
- Voice calls do not accidentally enter video Picture-in-Picture.
- Group signaling rejects mismatched media types and unauthorized leave events.
- Flutter regression assertions cover presentation policy.
- Version metadata is 0.3.0+13; Android Answer is retained until Dart acknowledges the matching incoming offer (resume race repair).
- 3–4 member mesh now shares one OS microphone/camera capture per group participant, disposes that capture only when the room closes, and displays local video preview.
- Android emulator smoke exercises HOME → stale Answer intent and repeated Answer for Activity lifecycle regressions.

## Acceptance still required

Successful same-commit GitHub Actions Flutter static analysis/tests, Android APK compilation and emulator launch, Windows release build. Real-device Windows ↔ Android answering, OEM overlay permissions, group 3–4 phone camera/audio bandwidth and reconnection testing are **not** certified by CI. Do not label production ready without field tests.
