# Current installer entry points

Use exactly one generated v7 edition archive from the verified release assets. It contains the common IPK, edition IPK, dependency-checking `install.sh`, and Windows `Update-EasyMode.bat` / PowerShell launcher. No passwords are embedded and no firmware is flashed automatically.

The historical HTML utility is informational only. The old v5 copying/launcher implementation is retired; current wrappers direct administrators to the actual v7 packages. See ../traffic/README.md for prerequisites and rollback.
