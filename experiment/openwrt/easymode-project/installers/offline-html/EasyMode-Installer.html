EASYMODE / TRAFFIC INTELLIGENCE

One shared monitor. Six editions.

This page is an installation guide, not a browser-based router installer.

  1. Choose a verified release matching your OpenWrt runtime and edition.
  2. Extract its offline archive into a separate directory.
  3. Run Update-EasyMode.bat on Windows, or install.sh on the router.
  4. Open /traffic/ and use your OpenWrt administrator account.

Existing router management is preserved. DNS observation is off by default. Firmware flashing is separate and requires an exact compatible target.
