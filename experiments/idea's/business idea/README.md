# Private Study & Creative Hub - Business Idea

**Status:** concept handbook v1.0 (16 October 2026)

This directory stores the business plan for an owner-operated Philippine student study/creative hub with private Solo, Duo+ and Group rooms and a small public cafe.

## Key decisions

1. **Pilot:** 1 Solo + 1 Duo+ + 1 Group plus 2-3 cafe tables in a legally suitable existing space. PHP 200,000 is a conditional budget ceiling, not a quote.
2. **Long-term target:** 8 Solo + 4 Duo+ + 2 Group, expanded in stages.
3. **Room prices under test:** PHP 49/hour Solo; PHP 79/hour Duo+ (up to 3); PHP 30/head/hour Group, four-person minimum, maximum six occupants.
4. **Cafe:** Solo/duo buy any item per person for two-hour seating. Groups of 3+ make a PHP 60/person upfront food/drink purchase. Additional seat-time test PHP 20/person/hour.
5. **Technology:** room Wi-Fi and normal charging included; cafe PisoWiFi and coin-operated outlets separately paid.
6. **Privacy:** no default cameras in rooms; visible security CCTV in appropriate public/corridor areas, subject to data protection requirements.

All legal/financial assumptions require local verification before building or accepting customers.
