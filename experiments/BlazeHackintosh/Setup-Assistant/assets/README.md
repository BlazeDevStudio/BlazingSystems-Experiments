# Visual assets

Bundled Lucide SVG icons: cpu, shield-check, hard-drive and download.
Upstream source: https://github.com/lucide-icons/lucide/tree/main/icons
License: ISC. See ../LICENSES/LUCIDE-ISC.txt.

The background gradients, button styling and layout are original project CSS,
so there are no stock-image royalties, online hotlinks or asset telemetry.
Asset paths are relative; the interface works offline when assets are copied along with index.html.

No Apple logos, Apple artwork or unauthorized macOS installer images are distributed.
