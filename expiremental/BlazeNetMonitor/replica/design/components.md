# UI components

1. **MonitorForm:** compact bottom-edge panel 452×55 logical pixels; two large, distinct status dots at left, upload/download value columns, orange sparklines. Hover: InfoForm; right-click: menu.
2. **InfoForm:** high-contrast hover dashboard with adapter, uptime, session/day/month counters and both target verdicts. Does not claim measured streaming capability.
3. **SettingsForm:** tabbed adapter, display, autostart and two independently configured target checks; validation on save.
4. **Connections form:** local TCP/UDP endpoint table with refresh, no process ownership.

Accessible label on main widget, simple high-contrast colors and semantic state text in hover panel. Text never relies on color alone for status meaning. Font Segoe UI and color palette are original.
